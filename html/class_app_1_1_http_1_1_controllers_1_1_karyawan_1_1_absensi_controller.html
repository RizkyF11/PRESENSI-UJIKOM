AbsensiController Class Reference

Controller untuk memanajemen absensi karyawan secara spesifik.

Kelas ini bertanggung jawab atas fitur dashboard karyawan, absen masuk, absen keluar, validasi lokasi GPS, validasi QR Code, hingga pengaturan jadwal berdasar shift aktif.
